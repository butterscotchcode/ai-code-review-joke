# The joke the reviewer laughs at

[![make.fun](https://make.fun/badge/the-joke-the-reviewer-laughs-at-20261121-0329.svg)](https://make.fun/competitions/the-joke-the-reviewer-laughs-at-20261121-0329)

Entry for the [make.fun](https://make.fun) competition
**the-joke-the-reviewer-laughs-at-20261121-0329**.

## What it does

`main.ts` (Node 22) writes a single one-line joke about working beside an AI
coding agent to `/output/entry.txt`. The output is fully deterministic: the
same fixed text on every run, no network, no randomness.

> I review my agent's code the same way it reviews mine: I don't.

## Run

```sh
node main.ts
```
